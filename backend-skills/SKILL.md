- **Node.js**：精通 JavaScript/TypeScript，熟悉 Express、NestJS

## 高级技能

### 数据库
- **关系型数据库**：MySQL、PostgreSQL、Oracle、SQL Server
- **NoSQL 数据库**：MongoDB、Redis、Cassandra、Elasticsearch
- **数据库设计**：数据库范式、索引优化、查询优化
- **事务管理**：ACID 特性、事务隔离级别、分布式事务
- **数据库连接池**：连接池配置和优化
- **读写分离**：主从复制、读写分离架构

### 缓存
- **Redis**：精通 Redis 数据结构、持久化、集群
- **Memcached**：了解 Memcached 缓存策略
- **本地缓存**：Guava、Caffeine、Ehcache
- **缓存策略**：缓存穿透、缓存击穿、缓存雪崩
- **缓存一致性**：缓存更新策略、一致性保证

### 消息队列
- **Kafka**：精通 Kafka 架构、分区、副本、消费者组
- **RabbitMQ**：熟悉 RabbitMQ 交换机、队列、路由
- **RocketMQ**：了解 RocketMQ 消息模型
- **消息可靠性**：消息确认、重试、死信队列
- **消息顺序**：顺序消息、幂等性保证

### 微服务
- **服务拆分**：领域驱动设计（DDD）、服务边界划分
- **服务注册与发现**：Eureka、Consul、Nacos
- **服务网关**：API Gateway、Zuul、Spring Cloud Gateway
- **负载均衡**：Nginx、HAProxy、Spring Cloud LoadBalancer
- **服务熔断**：Hystrix、Sentinel、Resilience4j
- **服务限流**：令牌桶、漏桶算法、Guava RateLimiter

### 安全性
- **认证授权**：JWT、OAuth2.0、SAML、CAS
- **数据加密**：对称加密、非对称加密、哈希算法
- **SQL 注入防护**：参数化查询、ORM 使用
- **XSS/CSRF 防护**：输入验证、CSRF Token
- **HTTPS**：SSL/TLS 配置、证书管理
- **安全审计**：日志记录、安全扫描

### 性能优化
- **代码优化**：算法优化、内存优化、并发编程
- **数据库优化**：索引优化、查询优化、分库分表
- **缓存优化**：多级缓存、缓存预热、缓存更新
- **异步处理**：线程池、异步编程、事件驱动
- **CDN 加速**：静态资源分发、边缘计算
- **性能监控**：APM 工具、性能指标分析

## 最佳实践

### 代码组织
- **分层架构**：Controller、Service、Repository 分层
- **模块化设计**：按业务模块划分代码
- **设计模式**：合理使用设计模式
- **代码复用**：提取公共组件和工具类

### API 设计
- **RESTful 规范**：遵循 RESTful 设计原则
- **版本控制**：API 版本管理策略
- **错误处理**：统一的错误响应格式
- **文档规范**：使用 Swagger/OpenAPI 生成文档
- **接口测试**：编写单元测试和集成测试

### 数据库设计
- **范式设计**：遵循数据库范式原则
- **索引优化**：合理创建索引，避免过度索引
- **查询优化**：避免 N+1 查询，使用 JOIN 优化
- **分库分表**：水平拆分、垂直拆分策略
- **数据备份**：定期备份、灾难恢复方案

### 缓存策略
- **缓存穿透**：布隆过滤器、缓存空值
- **缓存击穿**：互斥锁、热点数据预热
- **缓存雪崩**：随机过期时间、熔断降级
- **缓存更新**：Cache Aside、Write Through、Write Behind
- **缓存一致性**：延迟双删、订阅 Binlog

### 安全性
- **输入验证**：严格验证用户输入
- **权限控制**：基于角色的访问控制（RBAC）
- **敏感数据**：加密存储、脱敏展示
- **日志审计**：记录关键操作日志
- **安全扫描**：定期进行安全漏洞扫描

### 部署和监控
- **灰度发布**：金丝雀发布、蓝绿部署
- **回滚机制**：快速回滚策略
- **健康检查**：应用健康检查接口
- **性能监控**：监控关键性能指标
- **告警机制**：异常告警、故障通知
