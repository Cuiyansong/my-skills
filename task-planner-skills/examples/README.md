# Task Planner 代码示例使用说明

本文档提供了 Task Planner 技能文档中所有代码示例的详细使用说明、注意事项和最佳实践。

## 基础技能示例

### TaskModel.tsx
**功能**：任务数据模型和工具类

**使用场景**：
- 定义任务数据结构
- 任务创建和更新
- 任务比较和排序
- 任务状态判断

**使用说明**：
- 使用 `TaskModel.create()` 创建新任务
- 使用 `TaskModel.update()` 更新任务
- 使用 `TaskModel.isOverdue()` 检查任务是否逾期
- 使用 `TaskModel.compareByPriority()` 和 `TaskModel.compareByDueDate()` 进行排序

**注意事项**：
- 任务 ID 自动生成，格式为 `task_timestamp_random`
- 任务状态变更时自动更新 `completedAt` 时间戳
- 优先级值：low=1, medium=2, high=3, urgent=4

---

### TaskList.tsx
**功能**：任务列表组件，支持筛选和排序

**使用场景**：
- 展示任务列表
- 按状态、优先级、标签筛选
- 按优先级、截止日期、创建时间排序

**使用说明**：
- 通过 `tasks` prop 传入任务列表
- 通过 `onTaskSelect` 处理任务选择
- 通过 `onTaskUpdate` 处理任务更新
- 通过 `onTaskDelete` 处理任务删除

**注意事项**：
- 逾期任务会显示红色背景
- 筛选条件可以组合使用
- 搜索功能不区分大小写

---

### TaskForm.tsx
**功能**：任务创建和编辑表单

**使用场景**：
- 创建新任务
- 编辑现有任务
- 设置任务属性（标题、描述、优先级、截止日期等）

**使用说明**：
- 传入 `task` prop 进行编辑，不传入则创建新任务
- 通过 `onSubmit` 处理表单提交
- 通过 `onCancel` 处理取消操作
- 支持标签选择和创建新标签

**注意事项**：
- 标题是必填字段
- 截止日期不能早于今天
- 估算工时必须在 1-1000 小时之间
- 标签数量有限制（默认 10 个）

---

### PrioritySelector.tsx
**功能**：优先级选择器组件

**使用场景**：
- 选择任务优先级
- 显示优先级徽章
- 使用优先级矩阵选择

**使用说明**：
- `PrioritySelector`：下拉选择器
- `PriorityBadge`：优先级徽章显示
- `PriorityMatrix`：可视化优先级矩阵

**注意事项**：
- 四个优先级：low, medium, high, urgent
- 每个优先级有对应的颜色
- 矩阵视图提供更直观的选择方式

---

### TagManager.tsx
**功能**：标签管理组件

**使用场景**：
- 为任务添加标签
- 管理可用标签
- 标签云展示

**使用说明**：
- `TagManager`：完整的标签管理
- `TagCloud`：标签云展示

**注意事项**：

## 常见问题

### Q: 如何处理大量任务？
A: 使用虚拟滚动、分页加载、延迟渲染等技术优化性能。

### Q: 如何实现实时协作？
A: 使用 WebSocket 或 Server-Sent Events 实现实时同步。

### Q: 如何处理数据冲突？
A: 使用乐观更新、版本控制、冲突解决策略。

### Q: 如何确保数据安全？
A: 使用加密、访问控制、审计日志、定期备份。

### Q: 如何优化移动端体验？
A: 响应式设计、触摸优化、PWA 支持、离线功能。
