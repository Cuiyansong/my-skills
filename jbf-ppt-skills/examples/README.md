# 示例说明

本目录包含技能的示例文件：

- `sample.md` —— 示例 Markdown 大纲，源自真实的「报表平台项目规划」项目（BI 平台 Q4 规划）
- `sample.pptx` —— 由 `sample.md` 生成的演示文稿（运行生成脚本后产生）
- `sample-BI-platform-Q4-plan.pptx` —— 原始参考 PPT（19 页），用于提取大纲内容

## 生成示例

在技能根目录执行：

```bash
python scripts/build_deck.py examples/sample.md -o examples/sample.pptx
```

或直接运行自测（会生成临时产物并断言）：

```bash
python scripts/self_test.py
```

## 示例大纲结构

`sample.md` 完整演示了技能支持的所有页面类型：

| 页面类型 | 示例内容 | 对应大纲写法 |
|---|---|---|
| 封面 | 报表平台项目规划 | frontmatter `title` / `subtitle` / `period` |
| 目录 | 01 产品规划 / 02 沟通协作计划 | `## 目录` + 列表 |
| 章节页 | 01 产品规划（架构升级/能力增强/智能辅助） | `# 01 产品规划` + 标签列表 |
| 内容页-表格 | 1.2 项目里程碑、1.4 图表升级、1.7 电子表格、1.8 归因分析 | Markdown 表格 `\| 列 \| 列 \|` |
| 内容页-步骤 | 1.5 审批流管控（4 步）、1.8 归因流程、1.9 移动端（3 步） | 有序列表 `1. 步骤` |
| 内容页-列表 | 1.3 新旧对比、1.6 智能辅助、1.11 智能问答、1.13 交互功能 | 无序列表 `- 条目` |
| 内容页-段落 | 1.10 HTTP数据源、各页说明文字 | 普通文本 |
| 结束页 | THANKS + 谢谢观看 | `## 谢谢` |

## 大纲要点速查

| 元素 | 写法 | 生成的页面 |
|---|---|---|
| frontmatter | `---` 包裹的 `title` 等 | 封面 |
| `# 01 产品规划` | 一级标题 | 章节页 |
| `## 目录` | 二级标题（特殊名） | 目录页 |
| `## 1.1 项目背景` | 二级标题 | 内容页 |
| `- 目标一` | 无序列表 | 项目符号 |
| `1. 步骤` | 有序列表 | 步骤条/编号列表 |
| `\| 列 \| 列 \|` | 表格 | 表格 |
| `## 谢谢` | 二级标题（特殊名） | 结束页 |

> 提示：连续的无序列表会自动合并为一个列表块；连续的有序列表（≤5 条）渲染为横排步骤条，超过 5 条渲染为编号列表。
