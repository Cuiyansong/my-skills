## 1.8 归因分析及报告

从指标异动到原因定位，再自动生成归因报告

| 归因类型 | 说明 |
| --- | --- |
| 维度归因 | 各维度项对核心指标变动的贡献 |
| 异动分析 | 监控核心指标是否异常波动 |
| 指标归因 | 相关指标对核心指标变动的贡献 |

归因配置与报告流程：

1. 选择归因类型（维度 / 异动 / 指标）
2. 配置核心指标（数据集 · 聚合方式 · 指标属性）
3. 异动检测（Holt-winters / Prophet 或规则）
4. 设置拆解方式（维度拆解 · 指标拆解 · 分组维度）

归因报告：自动生成，按「观察日 T-1 → 报告日 T」定时产出；结论解读按贡献度排序；支持导出与消息订阅。

## 1.9 移动端仪表盘

增加手机端查看仪表板的方式，通过H5网页链接的方式嵌入系统

1. 选模板：使用自动布局仪表板创建模板
2. 配布局：使用网格式布局填充需要展示的图表或报表
3. 发布分享：发布仪表板，可使用密码和有效期等方式

使用效果：根据不同尺寸手机自适应大小屏幕，支持点击和滚动查看数据。
