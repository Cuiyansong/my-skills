# JBF 样式规范（提取自 template.pptx）

> 本文件是「JBF 大数据 PPT 设计专家」技能的样式权威定义，由模板
> `assets/template.pptx` 提取并固化。生成脚本（scripts/）中的颜色、字体、
> 布局常量必须与本文件保持一致；如需改版，先改本文件，再同步脚本常量。

## 2. 模板结构（5 页 = 5 种页面类型）

新模板精简为 **5 页，每种页面类型一页**，作为版式样例：

| 页 | 页面类型 | 作用 |
|---|---|---|
| 1 | 封面 cover | 全页背景 + 标题 + 渐变条 + 汇报人/部门/日期 |
| 2 | 目录 toc | 左侧背景 + 目录条目 |
| 3 | 章节 section | 大图标（不套框）+ 章节编号 + 标签 |
| 4 | 内容 content | 标题竖条 + 标题 + 正文区 |
| 5 | 结束 thanks | THANKS + 谢谢观看 + 副标题 + 分隔线 + 公司名 |
