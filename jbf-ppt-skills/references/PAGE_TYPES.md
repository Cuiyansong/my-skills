# 页面类型定义与 Markdown 大纲映射

> 本文件定义技能支持的页面类型、每种类型在 Markdown 大纲中的写法，
> 以及生成脚本如何将其渲染为幻灯片。生成逻辑见 `scripts/builder.py`。

## 1. 大纲语法总览

大纲为 Markdown，**一级标题（`#`）定义章节**，**二级标题（`##`）定义页面**，
页面正文决定页面类型。

```
# 第一章 产品规划            ← 章节 → 生成「章节页 section」
## 1.1 项目背景              ← 内容页 content
正文段落与列表……

## 目录                      ← 特殊页 toc
- 产品规划
- 沟通协作计划

# 第二章 沟通协作计划        ← 又一个章节页
## 2.1 沟通机制              ← 内容页
```

## 2. 页面类型

### 2.1 封面 cover

- **触发**：Markdown 大纲文件顶部的 H1 标题（第一章之前），或在脚本中显式传入。
- **字段**（脚本参数或 frontmatter）：
  - `title` 主标题（必填）
  - `subtitle` 一句话主旨（20–30 字）
  - `period` 规划周期（如 `2026 Q4 — 2027`）
  - `presenter` 汇报人、`department` 部门、`date` 日期
- **渲染**：全页背景图 + 右上 logo + 主标题 + 五段渐变条 + 副标题 + 底部三栏（汇报人/部门/日期）。

### 2.2 目录 toc

- **触发**：二级标题文本为「目录」「大纲」「CONTENTS」之一。
- **内容**：该页下的列表项，每项为一个目录条目（`编号. 标题 - 说明`）。
- **渲染**：左侧背景图 + 「目 录 / CONTENTS」+ 右侧条目卡（浅蓝底、编号、标题、说明）。

### 2.3 章节 section

- **触发**：一级标题（`# 01 产品规划` 或 `# 产品规划`）。
- **字段**：
  - `number` 章节编号（如 `01`，可从标题前缀提取）
  - `title` 章节名
  - `tags` 标签（该章节 H1 下紧邻的列表项）
- **渲染**：左侧竖条装饰 + 大图标 + 大号编号 + 章节名 + 标签胶囊 + 底部装饰条 + 页脚。

### 2.4 内容 content（默认）

- **触发**：二级标题（`## 1.1 标题`），非特殊类型。
- **字段**：
  - `number` 编号（如 `1.1`）
  - `title` 标题
  - `subtitle` 副标题（标题下一行普通文本，可选）
  - `body` 正文（段落 / 无序列表 / 有序列表）
- **渲染**：右上 logo + 标题竖条 + 标题 + 副标题 + 正文区 + 页脚 + 页码。
- **正文子类型**：
  - `bullets`：无序列表 → 项目符号列表
  - `cards`：列表项带 `|` 分隔或使用表格 → 卡片网格
  - `steps`：有序列表 → 步骤/流程条
  - `paragraphs`：普通段落 → 文本框

### 2.5 结束 thanks

- **触发**：二级标题文本为「谢谢」「致谢」「THANKS」「结束」之一；或自动在末尾追加。
- **渲染**：THANKS 大字 + 谢谢观看 + 项目名·周期 + 分隔线 + 公司名·NORTHKING + 页脚。

## 3. 溢出与适配规则

- 内容页正文超过版心高度时，按以下顺序处理：
  1. 缩小字号（最低 9pt）；
  2. 缩小行距；
  3. 拆分为多页（同一标题，页尾加「(续)」）。
- 列表项超过 8 条时自动拆分。
- 超长文本自动换行，不截断（除非单页实在放不下且无法拆分）。

## 4. 校验规则（scripts/validate.py）

生成后自动校验：
1. 文件存在且可被 python-pptx 打开；
2. 页数 ≥ 1 且与大纲页面数一致（±1 允许封面/结束页自动补）；
3. 无空页（每页至少一个含文字的形状）；
4. 无文字溢出画布（shape 右/下边界不超过画布 ± 0.1 英寸容差）；
5. 关键元素存在：封面含主标题、内容页含标题竖条颜色。
