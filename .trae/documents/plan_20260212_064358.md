## 后端开发专家技能文档创建计划

### 1. 创建文件夹结构
- 创建 `/Users/stephencui/Documents/Projects/my-skills/backend-skills/` 文件夹
- 创建 `/Users/stephencui/Documents/Projects/my-skills/backend-skills/examples/` 文件夹

### 2. 创建 SKILL.md 文档
包含以下章节：
- **元数据**：name 和 description（参考 React skills 格式）
- **基础技能**：核心概念、开发工具
- **高级技能**：数据库、缓存、消息队列、微服务、安全性、性能优化
- **生态系统**：后端框架、数据库、ORM、消息队列、容器化、监控
- **项目经验**：项目类型、团队协作
- **最佳实践**：代码组织、API设计、数据库设计、缓存策略、安全性、部署监控
- **学习资源**：官方文档、在线课程、社区资源
- **技能评估**：初级、中级、高级、专家

### 3. 创建代码示例文件（约15个）
- 基础技能示例：RESTful API、数据库连接、缓存使用
- 高级技能示例：数据库事务、消息队列、微服务配置
- 生态系统示例：Spring Boot、Django、Express、FastAPI、ORM、Docker、Kubernetes

### 4. 文档特点
- 采用与 React skills 相同的格式和结构
- 所有代码示例以独立文件方式存储在 examples 文件夹
- SKILL.md 中使用引用链接指向示例文件
- 涵盖后端开发的核心技术和最佳实践
